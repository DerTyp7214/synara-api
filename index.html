Synara insights

Views generated from the synara-api repository, rebuilt on every push to master.

  • Relation map

    The system topology with every runtime flow. Further views cover credentials, the API surface, pipelines, workers, events, startup, the build, packages, classes and the database schema.

  • Commit statistics

    Commits and line counts over time for synara-api, common-rpc, SynaraDesktop and synara-android, together and per repository.

  • Server UI catalogue

    Every server-driven UI contribution with its kind, slot, access and source, grouped by the slot it appears in.

  • Migration timeline

    Every Flyway and custom migration from the git history, with the tables it touches and the commit that added it.
