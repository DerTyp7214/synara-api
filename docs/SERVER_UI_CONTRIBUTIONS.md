Every server-driven UI contribution the server registers at startup, grouped by the source that registers it. Kinds are entries of [UiContributionKind](MODELS.md#devdertypuiuicontributionkind). Titles are the English texts.

External plugin JARs register their contributions under their own plugin id. They are not listed here. A running server lists every contribution visible to the current user through [IUiService.listContributions](RPC_SERVICES.md#devdertypservicesiuiservice-listcontributions).
